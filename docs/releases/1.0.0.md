# Apple Mail Triage v1.0.0

首个稳定开源版本，包含本地 MailBridge、Codex `email-triage` skill、每周单一对话分发器模板和中文使用说明。

## 下载哪个文件

- M1/M2/M3/M4/M5 等 Apple 芯片：下载文件名含 `arm64` 的 ZIP。
- Intel 芯片：下载文件名含 `x86_64` 的 ZIP。
- 每个 ZIP 旁边的 `.sha256` 文件用于校验下载完整性。
- 也可以直接下载 GitHub 自动生成的 Source code，按照源码安装方式编译。

## 安装

解压后在 Terminal 进入文件夹，执行：

```sh
./install.sh
printf '%s' '{"action":"setup"}' \
  | "$HOME/Applications/MailBridge.app/Contents/MacOS/MailBridge"
```

详细步骤、Gatekeeper 提示、Codex 项目设置和自动整理配置请阅读压缩包内的 `README.zh-CN.md`，或仓库中的[中文使用说明](https://github.com/S0rryHorizon/apple-mail-triage/blob/main/docs/%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E.md)。

## 安全说明

发布包采用 ad-hoc 签名，但没有 Apple Developer ID 公证。请先核对 SHA-256；如果 macOS 阻止运行，请在“系统设置 → 隐私与安全性”中审核并选择仍要打开，不要全局关闭 Gatekeeper。

本项目不包含任何真实邮件、账户凭据、SQLite 状态、附件、报告或 automation memory。
